VELORIAN BANK — POST TRANSACTION BUTTON FIX

Fixed the Administrator > Transactions > + Post transaction button.

Changes:
- The Post transaction button now opens the transaction modal.
- Client accounts are populated when the modal opens.
- Current client balance and account currency are shown.
- Changing the client or transaction type updates the form.
- Deposit, withdrawal and administrator transfer workflows remain connected to the existing storage system.

INSTALLATION:
1. Extract this ZIP.
2. Replace your current Velorian Bank files with the extracted files.
3. Open index.html.
4. Log in as Administrator.
5. Open Transactions and click + Post transaction.

NOTE:
This remains a browser-based prototype using localStorage. A real financial production system requires server-side authentication, authorization, database transactions, audit logging and additional security controls.
