# Velorian Bank — Premium Golden-Style Homepage Update

This package keeps the existing Client/Admin banking pages and upgrades the public landing page with a premium, long-form banking layout inspired by modern financial websites.

## Included
- Fixed navigation with Velorian logo at left
- Home / Services / About / Security / Contact / Login navigation
- Cinematic Velorian Bank hero background
- Administrator and Client portal cards
- Global client / market statistics (illustrative prototype values)
- Services section
- About section — established in 2013
- Security section
- CTA section
- Contact/social section
- Responsive mobile navigation
- About and Contact modal panels
- Separate administrator and client login backgrounds

## Important
The homepage uses illustrative fictional company figures (2.8M+ clients, 70+ markets). Replace them with verified figures if Velorian becomes a real organization.

Open `index.html` with Live Server.
