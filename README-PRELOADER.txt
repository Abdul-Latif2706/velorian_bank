VELORIAN BANK — PREMIUM PRELOADER UPDATE
=========================================

This package adds the same premium preloader to every HTML page:
- Homepage
- Administrator login
- Administrator dashboard
- Client login
- Client first-login/password setup
- Client dashboard

The preloader uses the Velorian Bank logo, animated gold/silver-style rings,
a subtle navy background, loading progress animation and a short minimum
display time so the transition feels intentional.

IMPORTANT:
1. Extract this ZIP completely.
2. Open the extracted project in VS Code.
3. Run index.html with Live Server.
4. Do not open HTML files from inside the ZIP preview.

Existing banking functionality and project files are preserved.
